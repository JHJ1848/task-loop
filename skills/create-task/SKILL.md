# 新建独立任务

1. **定界。** 单独写任务标题、用户原意、目标、必要背景和可观察的验收条件。标记 `EXPLORE` 或 `WORK`，写入任务附已授权的文件白名单。只带入本任务需要的旧上下文。
2. **在当前会话开任务。** 用户只要求开任务时，就地建立任务单。按用户授权和会话职责决定是否实施。只拟单时返回草稿。
3. **发给已有专题。** 用户明确要求派单时，按[派遣手册](references/dispatch-runtime.md)核对权限、正式会话和派发方式。每条 `WORK` 指定加载 `bugfix-dev`。无可用专题时保留待派发任务单。
4. **回报。** 给出任务标题、所在会话或接收专题和实际状态。以宿主回执确认派发，以交付证据确认完成。

单独授权的会话创建交由 `new-session` 处理。
